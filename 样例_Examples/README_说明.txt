ListenForge 样例 / Examples
===========================

两个真实样例,展示"上传练习卷 → ListenForge 自动生成听力 MP3"。
Two real examples: upload a worksheet → ListenForge generates the listening MP3.

样例 1 / Example 1
  输入 Input:  Unit 2小练习.pdf   (文字型 PDF 练习卷 / text PDF worksheet)
  输出 Output: 2B_Unit_2_full.mp3 (生成的完整听力音频 / generated full audio)

样例 2 / Example 2
  输入 Input:  mx.png             (图片练习卷 / image worksheet)
  输出 Output: project_full.mp3   (生成的听力音频 / generated audio)

每组的 PDF/图片是原始练习卷,mp3 是用 ListenForge 一键生成的听力音频。
The PDF/image is the source worksheet; the mp3 is what ListenForge produced.
